# Acessibilidade à Nutrição: Do Global ao Brasil

Um painel interativo de visualização de dados que explora o custo de dietas saudáveis ao redor do mundo (dados da FAO) e apresenta um panorama detalhado da insegurança alimentar no Brasil.

Acesse o projeto em funcionamento: https://mviniciusmonteiro.github.io/data-visualization/

---
Execução:
1. Abra o terminal na pasta do projeto.
2. Execute o comando:
   python -m http.server
